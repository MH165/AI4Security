# AI4Security 🛡️🤖

Welcome to **AI4Security**. This repository contains coursework, notes, and practical laboratory activities exploring the intersection of Artificial Intelligence and Cybersecurity. 

The primary focus is on understanding the fundamental concepts of Machine Learning (ML) and Deep Learning (DL), followed by a deep dive into the security vulnerabilities of AI models and the techniques used to defend them.

## 📚 Topics Covered

* **Machine Learning & Deep Learning Foundations:** Core concepts, algorithms, and training pipelines.
* **Adversarial Machine Learning:** Exploring how AI models can be compromised.
* **Evasion Attacks:** Generating adversarial examples to fool trained classifiers.
* **Data Poisoning:** Analyzing vulnerabilities in the training phase and backdoor insertions.
* **Model Security & Defenses:** Techniques for hardening models, such as adversarial training, defensive distillation, and robustness evaluation.

## 📂 Repository Structure

* `01_ML_Foundations/`: Basics of Machine Learning models, data preprocessing, and evaluation.
* `02_DL_Architectures/`: Neural networks, CNNs, and sequence models.
* `03_Adversarial_Attacks/`: Scripts and notebooks demonstrating evasion and poisoning attacks on ML/DL models.
* `04_Defensive_Mechanisms/`: Implementations of techniques to secure and evaluate model robustness.
* `Labs_and_Projects/`: Hands-on activities and course assignments.
